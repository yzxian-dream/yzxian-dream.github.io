APIKEY项目

Overview

Legacy V1 public API Token (Account Token) are managed by psd in user management. The token is account token attached to user.

The new API Key will be attached to role rather than user and managed by SP Foundation service.

UI panel

infra

mysql、redis、springboot

ES search by Kibana:

serviceName: uic, componentName：apikey

other key words: category 31,activity 01 to load audit log

Project feature

Trend Vision one公共API密钥(jwt)在用户管理中由psd管理。token是关联到用户的用户令牌。在V1基础上，API密钥将附加到角色role而不是用户，并由uic控制台管理。Vision one后台将为V1基础客户维护API密钥
APIKeys 微服务提供了一个集中位置来创建和管理 API 密钥，可用于访问Trend Vision One Open API 或第三方应用程序集成，当用户访问公司的open api的时候，会去校验当前apikey是否存在role，存在的role是否有对应的permission。

项目之处实现了数据迁移，把之前的旧的可用apikey迁移过来，实现批量增删，条件过滤，分页查询，通过etag进行版本控制，避免资源更新时发生冲突。目前这几只api也已经是公司的openapi，提供给客户第三方集成使用
