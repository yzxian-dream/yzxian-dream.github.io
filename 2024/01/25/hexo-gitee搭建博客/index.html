hexo+gitee搭建博客

1. 安装步骤

  1. 安装node
  2. 安装git
  3. 此时应该在user当前目录，切换到root用户，sudo su
  4. npm install -g cnpm –registry=https://registry.npm.taobao.org
  5. cnpm install -g hexo-cli //安装hexo,这一步不要在blog目录下执行，否则blog里会自动生成文件，会使后面的指令报错
  6. 在eric_yao目录下创建blog文件夹，保证blog 是empty的 ,进入blog目录下
    • sudo hexo init
    • hexo s //启动hexo
    • hexo new “My New Post” //创建新文章
    • cnpm install –save hexo-deployer-git //安装部署工具
    • hexo cl && hexo g && hexo d //部署到远端

https://github.com/JoeyBling/hexo-theme-yilia-plus/pull/63

2 部署过程中遇到的问题

  • 无法显示头像图片：

    解决方法
    原来修改头像配置，不光需要修改yilia主题下的yml配置文件还需要修改hexo主目录下的_config.yml文件。

    找到post_asset_folder选项，将其设置为如下：

    post_asset_folder: true//开启显示图片设置

    再次重试，完美解决问题。

    其中：

    favicon: /img/header.png//设置的是浏览器标签页显示的图片

    avatar: /img/head.png//设置博客作者头像
